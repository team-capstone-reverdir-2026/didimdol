# persona-research

AI 내담자 페르소나(침묵저항형/인정요구형) 설정집을 만들기 위한 데이터 분석 스크립트 모음입니다.


## 데이터 출처 & 라이선스

### AnnoMI
- 출처: https://github.com/uccollab/AnnoMI
- 라이선스: 별도 LICENSE 없음. README에 연구 목적 공개 명시, 연구에 사용 시 인용 요청
- 인용:
  ```
  Wu, Z., Balloccu, S., Kumar, V., Helaoui, R., Reiter, E., Reforgiato Recupero, D., & Riboni, D. (2022).
  Anno-MI: A Dataset of Expert-Annotated Counselling Dialogues. ICASSP 2022.
  ```

### ESConv
- 출처: https://github.com/thu-coai/Emotional-Support-Conversation
- 라이선스: 학술 연구 목적 사용만 허용 (CC-BY-NC-4.0, Tsinghua CoAI Group)
- 인용:
  ```
  Liu, S., Zheng, C., Demasi, O., Sabour, S., Li, Y., Yu, Z., Jiang, Y., & Huang, M. (2021).
  Towards Emotional Support Dialog Systems. ACL 2021.
  ```

> 본 프로젝트는 비영리 학술/포트폴리오 목적으로 두 데이터셋을 사용합니다.
